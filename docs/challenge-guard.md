- Start Balance: 50,000 USD
- Profit Target: 2,500 USD
- Maximum Loss: 1,500 USD
- Personal Daily Loss Limit: 150 USD
- Risk per Trade: 75 USD
- Maximum Losing Trades: 2
- Maximum Trades: 3

Locks:

- daily loss
- drawdown
- max trades
- max losing trades
- daily profit
- consistency
