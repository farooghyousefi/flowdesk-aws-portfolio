# Journal

The journal is local SQLite data linked to the selected replay session. Entries store date, session, symbol, direction, setup, entry, stop, targets, exit, contracts, risk/result USD, result R, optional screenshot path, decision snapshot, risk snapshot, market context, notes, emotion, mistake tags, and timestamps.

Supported actions:

- Create and update; double-click a row to edit
- Delete with browser confirmation
- Filter by date, direction, setup, symbol, notes, or mistake tag
- CSV export and versioned JSON backup
- JSON import

No cloud synchronization occurs. Exports are served only by the local market service.
